# Project instructions

Project-level rules for this repo. Global rules (which apply to all projects
and all agent tools) live in `agents/AGENTS.md` and are symlinked into
`~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.config/opencode/AGENTS.md`,
and `~/.pi/agent/AGENTS.md`. This file only adds rules for work done inside
this repo.

## Always

- After finishing any update to this repo (adding an app, changing a config,
  migrating the setup, etc.), update the README.md at the end - keep the
  "What it contains" list and the change log in sync with what the repo
  actually holds.
